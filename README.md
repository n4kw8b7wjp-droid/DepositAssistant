存单助手（飞牛 FN 应用）｜应用介绍
定位说明：本应用为运行在飞牛 FNOS 平台的本地存单台账工具，面向个人、小店、家庭做资产记录，**无云端强制上传、不上传用户数据到第三方服务器。

应用简介
存单助手是一款部署于飞牛 FNOS 的本地台账记录工具，主要用于管理定期存单、大额存单、结构性存款等各类存款凭证信息。所有业务数据默认存储在您自己的 NAS 本地，数据控制权归使用者本人，适合喜欢把资产台账托管在自有 NAS、不想把存单敏感信息提交给外部云平台的用户。

核心功能
存单台账录入
支持录入存单类型（定期存单、大额存单等）、存入银行、账号后四位、存款金额、年利率、起存日期、到期日期、存期、支取方式、备注等自定义字段。支持区分不同账户、不同存放人。
到期提醒
内置本地提醒能力，在存单临近到期时应用内显示即将到期存单，方便及时安排转存或者支取。
台账检索与筛选
支持按银行名称、到期时间、存单类型快速筛选、搜索存单记录，方便存量存单较多时快速定位。
基础统计汇总
自动统计全部存单本金总额、即将到期资产，以简单汇总视图展示，仅做统计展示，所有计算基于你手动录入的数据。
数据导出与备份
支持台账导出为通用文件做离线备份；配合 FNOS 本身的快照、备份机制，可对整个应用数据目录做 NAS 层面的备份保护。
数据安全说明
全部业务数据存储在您自己的飞牛 NAS 本地存储，应用本身不会主动把存单信息上传到任何外部服务器，不存在厂商后台收集存单信息的行为；
数据库文件由应用做本地加密存储（应用独立加密），仅在当前飞牛实例内可正常读取；
风险提示：NAS 本身属于网络存储设备，请做好基础安全防护：不要随意把飞牛端口对公网暴露、设置强管理员密码、定期给 FNOS 系统更新补丁；如果 NAS 被非法入侵，本地存储的数据同样存在泄露风险；
适用人群
家庭理财，有多张银行定期存单、国债，需要统一记录到期时间的个人；
小商户、个体户，有定期存款，需要一个本地台账管理，不想使用手机云记账软件；
NAS 爱好者，偏好敏感资产数据保存在自己私有 NAS，不信任第三方在线记账平台；
